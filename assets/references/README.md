# Ocean Adventure boat references

`ocean-boats-v2-reference.png` was generated with the built in Imagegen tool and saved into this project. It is a design reference for original geometry authored by `scripts/build_ocean_boats_v2.py`, not a gameplay screenshot or a ready made 3D asset. The tool did not expose a selectable image model version.

## Final image generation prompt

Use case: stylized-concept. Asset type: realistic marine vessel reference sheet for a playable browser diving expedition game, to be modeled in Blender. Create ONE landscape professional concept/reference sheet, two clearly separated rows, TWO ORIGINAL boat designs, each consistent across a port-side elevation, top deck plan, and large three-quarter rear perspective. Row one: a believable 42-meter explorer yacht, white curved hull with deep navy lower stripe, brushed metal details, wraparound dark glass bridge, teak aft work deck, a broad low swim platform with dive ladder, oxygen tank racks, discreet small deck crane, aft transom doors, two deck levels, radar mast. Practical luxury research expedition boat, not a box stack. Row two: a believable 28-meter fast research launch, white and slate hull with restrained orange identification accents, single streamlined enclosed wheelhouse, open stern sample work area, diving platform and ladder, rubber fenders, compact radar arch, twin propeller inboard drives, subtly different hull silhouette. High fidelity photorealistic 3D product renders, physically plausible smooth hulls, accurate vessel proportions and continuous curved bow, clear deck layout suitable for building geometry. Dry neutral light gray studio, no ocean occlusion, all full vessels inside frame. Small tasteful labels only 'AURORA 42' and 'VOYAGER X'; no other text, no logos, no people, no watermark. Keep viewpoints internally consistent. This is modeling reference, not gameplay screenshot.

## Material maps

`teak-color.png`, `teak-normal.png`, and `teak-roughness.png` are deterministic material maps generated by the boat builder. They are embedded in each exported GLB, so the browser does not require the reference folder at runtime.
